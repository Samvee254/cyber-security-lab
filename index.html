Objective

Design a lightweight, real-time SOC-style monitoring system that tracks system resources, network activity, and login behavior — detecting anomalies and displaying everything on a live Flask dashboard.

Architecture
  • scripts/monitor.py · anomaly_detector.py · alert_engine.py · dashboard.py
  • data/Baseline profiles & CSV metric history for trend analysis
  • logs/Auto-generated security reports saved after each session
  • dashboards/6-panel SOC dashboard screenshots & configs
Key Findings

Detected 5 failed sudo login attempts in real-time with timestamps. Monitoring 22 active network connections and tracking top processes by CPU/memory.

AI anomaly detector compares live stats (CPU 9.9%, Mem 32.9%) against trained baseline (CPU 0.1%, Mem 29.7%) — flagging deviations automatically. Reports auto-saved to logs/.
